# Сонная стройка (Dream Building) — v0.4

Dual-world песочница на **Godot 4.7.2**: строишь во сне, в явь забираешь только заякоренное. Хардкор: бесконечные чанки, Шовники и «призраки», три типа реагентов, инвентарь, сейв на диск.

## ROADMAP / хардкор-столпы

1. **Враги** — Шовник + элита; 4 типа «враг1»…«враг4» (ИИ как у призраков Pac-Man); спавн только после **второго** выхода из сна.
2. **Бесконечный мир** — чанки 16×16 load/unload, руины домов, озёра, реагенты.
3. **Survival** — дефицит якорей, кража ресурсов, реагенты с капом 100, 5 слотов инструментов.

## Что нового в v0.4

- В чанках Яви появляются три реагента: **реагент1** (янтарный), **реагент2** (бирюзовый), **реагент3** (фиолетовый). Рядом с руинами шанс выше. Счётчик каждого типа — до 100.
- Мобы не трогают игрока, пока тот дважды не выйдет из сна (чтобы освоиться). Счётчик `dream_exit_count` пишется в сейв.
- Четыре врага с ИИ призраков Pac-Man:
  - **враг1** — идёт прямо на игрока (Blinky);
  - **враг2** — целится в точку перед игроком (Pinky);
  - **враг3** — зеркалит вектор от враг1 через игрока (Inky);
  - **враг4** — преследует издалека и уходит в свой угол, если близко (Clyde).
  Общий таймер режимов scatter (7 с) / chase (20 с). Шовники тоже остаются.
- Инвентарь на **5 слотов**: 1 — Гвоздь, 2 — Клин, 3–5 — свободные под предметы/оружие/инструменты. Реагенты считаются отдельно.
- В чанках — **руины** старых домов (серые стены с проёмами) и **озёра**; вода замедляет шаг примерно до 40%.

## Сохранение (`user://sonnaya_save.json`)

| Когда | Что |
|--------|-----|
| Авто | После каждого пробуждения (wake transfer) |
| Авто | При закрытии окна |
| F5 | Ручное сохранение |
| F9 | Загрузка |
| Старт | Если файл есть — автозагрузка |

Ключевые поля JSON: `version` (2), `world` (`wake`/`dream`), `clarity`, `reagents`, `reagent_counts`, `item_slots`, `selected_slot`, `dream_exit_count`, `collected_reagent_ids`, `dust`, `nails`, `wedges`, `selected_anchor`, `awake_time`, `world_seed_wake`, `world_seed_dream`, `wake_blocks` / `dream_blocks` (ключи `"x,y,z"`), `pending_anchors`, `player_pos`, `threat` (включая `ghost_count` / `ghost_mode`), `reason`.

Старые сейвы v0.3 подхватываются: одиночное поле `reagents` переезжает в `реагент1`.

Путь на диске: каталог user data Godot для этого проекта (не рядом с zip).

## Игровой луп

1. Явь — реагенты (`E`). Первые два цикла сна безопасны: мобы появятся только после второго пробуждения.
2. Кровать `E` → Сон.
3. Строй `ЛКМ`/`ПКМ`, якорь `1`/`2` + `Q`.
4. `C` — крафт **выбранного** якоря из осыпи (Гвоздь 5 / Клин 15).
5. `F` — проснуться (автосейв). Заякоренное → явь, остальное → осыпь.

## Известные упрощения

- Сейв не пишет геометрию чанков (шум от seed); только voxel-билды + инвентарь + угроза-мета + собранные реагенты.
- Крафт предметов/улучшений из трёх реагентов — заготовка: типы и счётчики уже есть, рецепты появятся позже.
- Нестабильный шов — таймерная потеря блоков яви без награды.
- Greybox BoxMesh, без звука.

## Архив и размер релиза

Исходный `.rar` (~1.7–1.8 МБ) почти целиком состоит из кэша редактора Godot (папка `.godot/`: shader_cache, импорт иконки, раскладка редактора). Игровых ассетов (текстур, аудио, addons) в том архиве не было — только `scripts/`, `scenes/`, `project.godot`, `icon.svg` и README.

Релизный zip специально **не** включает `.godot/` и `.git/`: кэш Godot пересоздаёт сам при открытии проекта. Все 40 исходных файлов прошлой версии на месте; v0.4 добавляет `scripts/enemy_ghost.gd` и правки поверх них.
