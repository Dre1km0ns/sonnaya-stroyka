# Сонная стройка (Dream Building) — v0.11

Dual-world песочница на **Godot 4.7.2**: строишь во сне, в явь забираешь только заякоренное. Хардкор: бесконечные чанки, Шовники и «призраки», три типа реагентов, инвентарь, сейв на диск.

## ROADMAP / хардкор-столпы

1. **Враги** — Шовник + элита; 4 типа «враг1»…«враг4» (ИИ как у призраков Pac-Man); спавн только после **второго** выхода из сна.
2. **Бесконечный мир** — чанки 16×16 load/unload, руины домов, озёра, реагенты.
3. **Survival** — дефицит якорей, кража ресурсов, реагенты с капом 100, инвентарь 9+27, осыпь за убийства.

## Что нового в v0.9

- Генерация чанков (`chunk_job.gd`) в `WorkerThreadPool`: шум, озёра/руины/поселения, пещеры, растительность, массивы мешей/коллайдеров. Рабочий поток — `RefCounted`, не Node; в дерево сцены попадает только готовый результат на главном потоке. Результаты устаревшего поколения отбрасываются. Стартовые/явно запрошенные чанки ждут worker; текущая симуляция текучей воды остаётся на главном потоке.
- Туман Alpha Minecraft: линейный, конец `16×радиус−8`, начало 35% этого расстояния; при радиусе 3 — 14–40 блоков, камера до 48. Круговая подгрузка вместо лишних углов квадрата. Оттенок травы детерминирован шумом сида.
- Факел — только слой луча 32, без столкновения с игроком/мобами. Анаконда ломает его с вероятностью 1/3 на контакт, успешное разрушение блокирует способность на 5 с.
- Добыча с 10 стадиями трещин; новые непрерывные изогнутые модели кирок и отдельные текстуры дерева/камня.
- После первого успешного крафта Меча2 флаг хранится в мире: обычные 50→188 HP (×3.75, округление вверх), Мать 500→1500 HP; Анаконда остаётся 2850. Препятствия на пути к игроку мобы добывают вдвое медленнее игрока с тем же инструментом (по умолчанию рука); не грызут произвольный соседний блок.
- Поселение: целевой лут 12 или 13 реагентов (среднее 12.75) против 3 в обычных руинах — ×4.25. Все типы; фактическое число ограничивается свободными точками.
- Броня уже настоящая: надеть переносом в подходящий слот или Shift+ЛКМ. Прочность сохраняется при переносе/сейве, при 0 вещь ломается, надетое выпадает при смерти. Общая между явью и сном.
- Луна: пиковая энергия **0.47**, раньше **0.78**; `moon <value>` меняет её для текущего мира, значение сохраняется. Плавное появление/закат луны сохранены.
- Имя «Меч» поднято над HP; управляющая подсказка сна больше не пишется в чат яви.

### Добыча — секунды
| Блок | Рука | Кирка (дерево) | Кирка2 (камень) |
|---|---:|---:|---:|
| Земля | 0.75 | 3.75 | 1.875 |
| Грунт / холм | 0.9 | 3.75 | 1.875 |
| Бревно | 3 | 3 | 3 |
| Камень | 7.5, без дропа | 3 | 1.5 |
| Глубинный камень | 15, без дропа | 6 | 3 |

Решение неоднозначности задания: как в MC, рука для доступного без инструмента блока использует `hardness×1.5` (земля 0.75, дерево 3), а неправильный инструмент для камня — `hardness×5` без дропа. Множитель tier1/tier2 кирок на камнях и земле равен 2. Твёрдость: земля 0.5, трава 0.6, листья 0.2, дерево/доски 2, камень 1.5, глубинный камень 3, песок 0.5, бедрок неразрушим.

### Броня
| Материал / станция | Рецепт шлем/грудь/ноги/ботинки | Защита по частям | Прочность по частям |
|---|---|---|---|
| Дерево / Лесопилка+ | 7 / 15 / 11 / 5 досок | 1 / 3 / 2 / 1 (кожа MC) | 165 / 240 / 225 / 195 (кольчуга MC) |
| Чешуя / Станок | 7 / 15 / 11 / 5 чешуи | 2 / 6 / 5 / 2 (железо MC) | 77 / 112 / 105 / 91 (золото MC) |

Анаконда роняет **6–22 чешуи** за победу, прочие награды не изменены. Защита — формула Java MC без toughness с пересчётом наших 100 HP к 20 HP MC. Удар 10 HP: без брони 10, полный деревянный комплект 8, чешуйчатый 5 (целочисленный урон округляется вверх). Износ каждого надетого предмета: минимум 1, далее `floor(урон/20)`.

### Консоль DevSeed
Только мир с сидом `6767676767`: **~ / Ё** открыть, **~ / Esc** закрыть; стрелки ↑/↓ — история, Tab — дополнение и перебор вариантов, Enter — выполнить. В обычном мире даже программный вызов команды запрещён.

```
help                         seed
spawn seam|elite|ghost|enemy1|enemy2|enemy3|enemy4|mother|anaconda|minion [count]
mob hp|damage|speed <value> [nearest|all|type]
mob tool hand|pickaxe|pickaxe2 [nearest|all|type]
kill all                     # без наград; боссы уходят со своей анимацией
time day|night|<hour>         # <hour> — часы HUD, например 9.5 = 09:30
moon <0..10>                  # 0.47 по умолчанию, сохраняется
tp spawn                     tp x y z
god                          fly
heal                         hp <value>
world wake|dream              cooldown reset
sword2 [on|off|toggle]         hardness <block> [hand|pickaxe|pickaxe2]
armor give wood|scale         give <item> [count]
setblock <block|air> [x y z]   # без координат — под прицелом
fill <block|air> x1 y1 z1 x2 y2 z2
fill <block|air> <radius>     # куб вокруг игрока
```

Мобы Яви создаются в яви, `world wake` переключит туда. Одновременно по одному боссу каждого вида; spawn обычных мобов ограничен 32 за команду. Fill — максимум 4096 клеток, относительный радиус 0–7, высота −31..128; может заменять строения и содержимое хранилищ — это намеренный dev-инструмент. Большой fill и явный телепорт могут синхронно ожидать генерацию, не являются бесшовным стримингом. `armor give` сразу надевает комплект. В DevSeed предметы бесконечны и не изнашиваются, проверка реального износа выполняется также в обычном мире smoke-тестом.

### Замер стриминга v0.9
Повторяемый headless CPU-probe: 49 одинаковых чанков, сид 6767676767, 60 FPS cap, один компьютер; `tools/chunk_hitch_probe.gd` (`-- --legacy` для старого пути).

| Метрика | Старый главный поток | WorkerThreadPool |
|---|---:|---:|
| Работа главного потока p95 / max | 12.198 / 14.785 мс | 1.312 / 1.364 мс |
| Межкадровый p95 / max | 16.704 / 16.833 мс | 16.750 / 16.792 мс |
| Кадров >33.34 мс | 0 | 0 |
| Стартовые 9 чанков / полная загрузка 49 | 74.782 / 573.929 мс | 84.157 / 772.602 мс |

Главный CPU-spike p95 меньше примерно на **89%**, но это **не обещание роста FPS**: в этом headless тесте уже не было кадров >33 мс. Старт и общий throughput стали медленнее из-за ожидания workers и вставки максимум одного результата за кадр. Замер не подменяет тест на видеокарте владельца. Для визуальной проверки использованы Xvfb + OpenGL3, скриншоты `v09_*.png`.

Дополнительно Xvfb/OpenGL3 (Mesa llvmpipe, одинаковая фиксированная траектория, камера летит без физического толкания): при движении p95 **50.000→40.993 мс**, p99 **55.891→46.331 мс**, средний **38.21→35.47 мс**. Худший единичный кадр **62.462→65.987 мс** — полностью фризы не исчезли; кадров >33.34 мс **213/262→184/282**. Это результат одного программно-рендерящего прогона, не обещание FPS на компьютере владельца. Вершины травы окрашены шумом в worker с сохранением слитых полос, без удорожания плоской земли до отдельных кубов. Сырые числа: `benchmarks/v0.9.json`, воспроизведение: `tools/perf_probe.gd` с `--perf nomobs` и `--legacy-generation` для старого пути.

1. Явь — реагенты (`E`). Первые два цикла сна безопасны: мобы появятся только после второго пробуждения.
2. Кровать `E` → Сон.
3. Строй `ЛКМ`/`ПКМ`, якорь выбирается `R` (полоса справа) и ставится `Q`.
4. `C` — меню крафта по центру экрана (гвоздь 10 / клин 100 / Якорь3 250 осыпи; во сне ещё верстак; у верстака — кирка и факел).
5. `F` — проснуться (автосейв). Заякоренное → явь, сон сохраняется.

## Известные упрощения

- В мирном режиме мобов нет, поэтому осыпь там почти не добыть. Мирный режим удобнее для стройки, дев-сид — для тестов.
- Иконки и текстуры блоков — пиксельные PNG 16×16 из `tools/make_textures.py` (иконки инструментов — спрайты, блоки — изометрические кубики).
- Лёгкая/экспертная сложность босса пока только в дизайн-доке.

- Сейв не пишет геометрию чанков (шум от seed); только voxel-билды + инвентарь + угроза-мета + собранные реагенты.
- Рецепты верстака легко расширять в `GameState.recipe_defs()` (поле `where`: `anywhere` / `dream` / `workbench`).
- Нестабильный шов — таймерная потеря блоков яви без награды.
- Враги используют жадный A* по сетке XZ, не NavigationServer.
- Враги — CC0-модели Quaternius; фоновая музыка пользователя (`assets/audio/music.mp3`) играет сразу при старте, отдельной кнопки выключения нет.

## Архив и размер релиза

Полный zip `Сонная стройка v0.9.zip` собирается через Python `zipfile`: включает исходники, ассеты (модели GLB, `music.mp3`, лицензии) и кэш `.godot/`, без каталога `.git/`. Godot 4.7.x открывает распакованный `project.godot` сразу.

В архив входят модели врагов/реагентов/босса и три музыкальных трека, поэтому он больше предыдущих версий.
