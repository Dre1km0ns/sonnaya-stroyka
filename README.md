# Сонная стройка (Dream Building) — v0.4.2

Dual-world песочница на **Godot 4.7.2**: строишь во сне, в явь забираешь только заякоренное. Хардкор: бесконечные чанки, Шовники и «призраки», три типа реагентов, инвентарь, сейв на диск.

## ROADMAP / хардкор-столпы

1. **Враги** — Шовник + элита; 4 типа «враг1»…«враг4» (ИИ как у призраков Pac-Man); спавн только после **второго** выхода из сна.
2. **Бесконечный мир** — чанки 16×16 load/unload, руины домов, озёра, реагенты.
3. **Survival** — дефицит якорей, кража ресурсов, реагенты с капом 100, 5 слотов инструментов.

## Что нового в v0.4.2

- Враги ищут кратчайший путь до игрока (A* по сетке высоты). Вода не запрещена: по ней можно идти, но медленнее и путь дороже.
- В руинах реагентов лишь умеренно больше, чем в поле (примерно 2–3 штуки), а не на каждой пустой клетке.
- Холмы до 4 уровней: визуал совпадает с коллизией (больше невидимых горок). Реагенты садятся сверху, а не внутри. Озёра глубже; вода — тонкая поверхность без боковых «стенок», берега рисуются со всех сторон.
- Убраны нижние предупреждения вроде «враг1 рядом!» и подпись «(макс. 100)» (лимит 100 на тип остался).
- Враги сталкиваются с игроком и блоками, стоят рядом и бьют блоки как зомби по двери, внутрь блока не заходят.
- У каждого типа врага своя модель из примитивов (лицензия CC0: `assets/LICENSE.txt`).
- Крафт из осыпи: гвоздь 10, клин/якорь 100, Якорь3 250 (зона 9×9×9). Меню на `C`.
- Цикл дня и ночи: 5 минут дня, затем ночь, плавная смена света.
- Не больше 7 врагов одновременно. Время сна увеличено вдвое (ясность тает медленнее).
- Верстак: 10 реагент1 во сне в меню крафта → ставите блок → гвоздь в явь. В яви `E` по верстаку открывает крафт инструментов: кирка = 2 реагент2 + 3 реагент3. Кирка ломает блоки яви (ЛКМ/ПКМ).

## Что нового в v0.4.1

- Реагенты в поле спавнятся примерно в 5 раз реже (−80%). Руины стали редкими, но внутри/рядом лежит большое гнездо реагентов.
- Сон больше не очищается при пробуждении: незаякоренное остаётся во сне и в сейве, можно достраивать. Заякоренное по-прежнему переносится в явь с той же высотой ячейки (стартовая площадка сна теперь на y=0, как земля яви).
- Озёра — неровные впадины ниже земли: игрок проваливается примерно на половину роста и замедляется.
- Враги сталкиваются друг с другом, умеют запрыгивать на холмик высотой в 1 блок, обходят воду и стены; скорость всех типов снижена на 40%.

## Что нового в v0.4

- В чанках Яви появляются три реагента: **реагент1** (янтарный), **реагент2** (бирюзовый), **реагент3** (фиолетовый). Рядом с руинами шанс выше. Счётчик каждого типа — до 100.
- Мобы не трогают игрока, пока тот дважды не выйдет из сна (чтобы освоиться). Счётчик `dream_exit_count` пишется в сейв.
- Четыре врага с ИИ призраков Pac-Man:
  - **враг1** — идёт прямо на игрока (Blinky);
  - **враг2** — целится в точку перед игроком (Pinky);
  - **враг3** — зеркалит вектор от враг1 через игрока (Inky);
  - **враг4** — преследует издалека и уходит в свой угол, если близко (Clyde).
  Общий таймер режимов scatter (7 с) / chase (20 с). Шовники тоже остаются.
- Инвентарь на **5 слотов**: 1 — Гвоздь, 2 — Клин, 3 — Якорь3, 4–5 — инструменты (кирка, верстак). Реагенты считаются отдельно.
- В чанках — **руины** старых домов (серые стены с проёмами) и **озёра**; вода замедляет шаг примерно до 40%.

## Сохранение (`user://sonnaya_save.json`)

| Когда | Что |
|--------|-----|
| Авто | После каждого пробуждения (wake transfer) |
| Авто | При закрытии окна |
| F5 | Ручное сохранение |
| F9 | Загрузка |
| Старт | Если файл есть — автозагрузка |

Ключевые поля JSON: `version` (3), `world` (`wake`/`dream`), `clarity`, `reagents`, `reagent_counts`, `item_slots`, `selected_slot`, `dream_exit_count`, `collected_reagent_ids`, `dust`, `nails`, `wedges`, `anchors3`, `day_time`, `selected_anchor`, `awake_time`, `world_seed_wake`, `world_seed_dream`, `wake_blocks` / `dream_blocks` (ключи `"x,y,z"`), `pending_anchors`, `player_pos`, `threat` (включая `ghost_count` / `ghost_mode`), `reason`.

Старые сейвы v0.3 подхватываются: одиночное поле `reagents` переезжает в `реагент1`.

Путь на диске: каталог user data Godot для этого проекта (не рядом с zip).

## Игровой луп

1. Явь — реагенты (`E`). Первые два цикла сна безопасны: мобы появятся только после второго пробуждения.
2. Кровать `E` → Сон.
3. Строй `ЛКМ`/`ПКМ`, якорь `1`/`2` + `Q`.
4. `C` — меню крафта (гвоздь 10 / клин 100 / Якорь3 250 осыпи; во сне ещё верстак).
5. `F` — проснуться (автосейв). Заякоренное → явь, сон сохраняется.

## Известные упрощения

- Сейв не пишет геометрию чанков (шум от seed); только voxel-билды + инвентарь + угроза-мета + собранные реагенты.
- Рецепты верстака легко расширять в `GameState.recipe_defs()` (поле `where`: `anywhere` / `dream` / `workbench`).
- Нестабильный шов — таймерная потеря блоков яви без награды.
- Враги используют жадный A* по сетке XZ, не NavigationServer.
- Greybox-примитивы, без звука.

## Архив и размер релиза

Исходный `.rar` (~1.7–1.8 МБ) почти целиком состоит из кэша редактора Godot (папка `.godot/`: shader_cache, импорт иконки, раскладка редактора). Игровых ассетов (текстур, аудио, addons) в том архиве не было — только `scripts/`, `scenes/`, `project.godot`, `icon.svg` и README.

Релизный zip специально **не** включает `.godot/` и `.git/`: кэш Godot пересоздаёт сам при открытии проекта. Все 40 исходных файлов прошлой версии на месте; v0.4 добавляет `scripts/enemy_ghost.gd` и правки поверх них.
