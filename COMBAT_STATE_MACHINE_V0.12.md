# COMBAT_STATE_MACHINE V0.12

Общий контроллер: `scripts/boss_combat_sm.gd` (`RefCounted`, не Node). Подключается обоими боссами. Не дублирует сцену и не создаёт второй источник HP.

## Фазы машины

`IDLE → TELEGRAPH → ATTACK → RECOVERY → VULNERABILITY → TRANSITION`, плюс `CUSTOM` для уникальных циклов (подкоп Анаконды, полёт Матери, кольцо, обвал каркаса).

Правила:

- У состояния есть конечный таймер. `timed_out()` обязателен для выхода; бесконечных боевых состояний нет (кроме смерти / ухода).
- `begin_attack(id)` + `can_hit(token)` — одна атака не может списать урон повторно каждый кадр. Токен учитывает номер атаки в логе.
- Стан, замедление и уязвимость живут **рядом** с фазой, а не вместо неё. Свет не имеет права держать `STUN`.
- `try_stun(duration, source, immunity)`:
  - отвергает `light` / `crossfire` / `crossfire2` / `crossfire3` / `torch_field` / `held`;
  - отвергает повтор, пока идёт стан или иммунитет;
  - длительность 0.15–1.5 с (по умолчанию 0.75);
  - иммунитет по умолчанию 2.5 с, не меньше длительности стана, отсчёт с момента успеха;
  - после стана вызывающий код обязан вернуть AI в рабочее состояние (`REST` у Анаконды).
- `apply_slow` / `apply_exposed` можно обновлять от света (это не стан).
- Смена фазы босса идёт через `TRANSITION` с неуязвимостью, пороги не проскакиваются.
- Смерть и рассвет (Анаконда уходит) снимают эффекты и чистят миньонов.

## Соответствие состояний Анаконды

Собственный `enum S` сохранён (UNDER, TELEGRAPH, BURST, REST, DIVE, …) и проецируется на общую машину:

| Состояние босса | Фаза SM | Заметки |
|---|---|---|
| IDLE / REST (ожидание) | IDLE / RECOVERY / VULNERABILITY | REST — окно урона светом |
| TELEGRAPH / трещины | TELEGRAPH | 1.1 с, направление читаемо |
| BURST / укус / рывок / удар по факелу | ATTACK | `can_hit` на укус и камни |
| DIVE / отступление | RECOVERY | |
| STUN | CUSTOM + CC stun | только event, затем REST |
| FAKE | CUSTOM | ложное появление; запрещено при заманивании |
| DASH | ATTACK | после — REST, тело не ломает факелы |
| TORCHSTRIKE | TELEGRAPH→ATTACK | предупреждение 1.3–1.5 с, затем удар по выбранному факелу |
| COIL | CUSTOM / ATTACK | сжатие 5.5→2.6 м; разрыв новым факелом → stun + окно |
| TRANSITION | TRANSITION | смена фазы, рев, неуязвимость |

Свет в 2+ источниках: SLOW+EXPOSED каждый тик **без** `try_stun` успеха. Диагностический вызов `try_stun(..., "light")` только считает отказ (`light_stun_attempts`), стан не ставит.

## Соответствие состояний Матери

| Состояние | Фаза SM | Заметки |
|---|---|---|
| IDLE | IDLE | |
| WINDUP / RAIN_WINDUP / MARKER / GUARD | TELEGRAPH | читаемый диск/тень |
| AIR (слэм), MELEE, RAIN, SCATTER, COLLAPSE | ATTACK | урон один раз на атаку |
| STAGGER / после удара | RECOVERY | |
| PLATE_OPEN / CORE / CORE_LONG | VULNERABILITY | кирка по пластине / меч по сердцу |
| TRANSITION | TRANSITION | 100–66 / 66–33 |
| COMBO | ATTACK | II фаза: слэм, затем ближняя |
| COLLAPSE | ATTACK→VULNERABILITY | финал ≤15% HP, затем длинное ядро |

`receive_weapon_hit(amount, weapon_id)` сохранён: кирка бьёт открытую пластину, меч — только открытое сердце, иначе отскок.

## Защита от повторного урона и невидимых ударов

- Каждая опасная атака имеет телеграф (трещины, тень, диск, подсветка факела).
- Контактный урон на земле имеет кулдаун; комбо-кап игрока не снят.
- Факел в руке не разрывает кольцо и не даёт DPS.
- После смерти/ухода эффекты и миньоны снимаются (как в v0.11.1, проверено smoke-очисткой).
