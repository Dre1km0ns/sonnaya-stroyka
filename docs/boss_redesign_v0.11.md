## 2. Анаконда (подробно — docs/boss_anaconda.md)
- Урон только от **поставленных** факелов; факел в руке и оружие — 0. *(Правка A5 убрала оглушение факелом из спеки.)*
- Перекрёстный огонь: 1 источник — обнаружение, 2 — ожог 13/с, 3+ — ×2 и вынужденный отход.
- Фаза I — трещины-телеграф; II — 3–4 зоны обвала + землеройки (≤2), гасящие факелы; III — кольцо, разрываемое новым факелом (45 урона).
- **Правка A5:** тело ломает факел каждой секцией при касании, без шанса/КД; гейт «после Матери» снят.
- Кеш факелов `GameState.torch_cells()`.
- HP 1250; ночь 420 с; цель TTK 150–210 с при 3 факелах + запас → сим: **187 с** (11/12), human_like 198 с (10/12).

## 3. Мать блоков (подробно — docs/boss_mother_of_blocks.md)
- 3 пластины × 6; кирка 2, кирка2 6; меч по броне 0 + отскок. `receive_weapon_hit`, `take_damage` — совместимость.
- После слэма пластина открыта 3.5 с → разбита → оглушение + ядро 2.6 с (×1.25).
- II: ударная волна + до 2 носильщиков (восстанавливают пластину при доставке). Скрытый хил от деревьев удалён.
- III: кирпичный дождь 4–6 с тенями, интервалами и навесом → длинное окно ядра 4.5 с. Броня не восстанавливается.
- Пересборка с телеграфом (маркер 1.6 с).
- HP 620 фиксировано; цель 90–140 с стартовым оружием → сим: **93 с** (12/12), кирка2+меч2 48 с, меч3 35 с.
- **Правка A4:** приход — 1% на каждый блок (угроза глубин только атмосфера); после первой победы — блоколиты 1/120, нейтральные, убийство вызывает Мать.
