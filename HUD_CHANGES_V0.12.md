# HUD_CHANGES V0.12

## Что было в v0.11.1

Компактная «батарейка» без подписей «H — хилка» и без строки «100 HP» (их убрали по просьбе игрока). Число HP внутри прямоугольника уже было, но не было явной пары текущее/максимум, отложенного следа урона, раздельных вспышек и аккуратной обработки смены максимума / смерти / возрождения.

## Что сделано

Файл `scripts/health_battery.gd`, размещение в `scripts/hud.gd`.

- Горизонтальная полоса **слева снизу** (отступ 16 px, размер 240×34).
- Подпись **«текущее / максимум»** (например `62 / 100`). Слова «HP» и подсказок про H на полосе нет.
- Плавная заливка (`FILL_SPEED 6.5`).
- Отложенный след урона: после попадания след держится `TRAIL_DELAY 0.35` с, затем догоняет (`TRAIL_SPEED 2.4`). При лечении след сразу подтягивается, «рана назад» не рисуется.
- Вспышка урона и вспышка лечения разделены (`_flash` / `_flash_heal`).
- Критическое HP (< 25%): ненавязчивый пульс рамки, без мигающего текста на весь экран.
- Смена максимума пересчитывает доли, след не торчит выше новой шкалы.
- Смерть: заливка уходит в ноль, `_dead_visual`. Возрождение: заливка растёт с нуля.
- Цвет по-прежнему зелёный → жёлтый → красный, атмосферный минимализм, без MMO-рамок.

## Источник данных

Полоса **не хранит** логическое HP игрока. Единственный вход — `set_hp(v, m)`, который HUD вызывает из `GameState.player_hp` / `PLAYER_MAX_HP` и сигнала `player_hp_changed`. `_shown_hp` / `_fill` — только отображение.

`hud.heal_indicator_state()` отдаёт `current`, `max` и флаг `bottom_left` для тестов. Smoke проверяет формат «N / M» и положение.

## Что не трогали

Автолечение **H**: отдельного слота нет, выбирается хилка с минимальным избытком, предмет списывается только после успеха, кулдаун прежний. Текстовых подсказок «H — хилка1» в хотбаре по-прежнему нет.
